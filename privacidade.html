Política de Privacidade

Resumo: o LiveClips BR acessa só o necessário para enviar ao TikTok os vídeos que você aprova, e tudo fica no seu computador.

1. Dados acessados

Com a autorização do usuário, o LiveClips BR recebe do TikTok as informações básicas do perfil (nome de exibição) e a permissão para enviar vídeos aos rascunhos da conta (escopos user.info.basic e video.upload).

2. Armazenamento

Os tokens de acesso ficam salvos apenas no computador do próprio usuário. Nenhum dado é enviado a servidores de terceiros, vendido ou compartilhado.

3. Uso dos dados

Os dados são usados exclusivamente para enviar ao TikTok os vídeos que o usuário aprovar.

4. Exclusão

O usuário pode desconectar a ferramenta a qualquer momento nas configurações do TikTok (Segurança → Gerenciar aplicativos) e apagar os dados locais excluindo a pasta do programa.

5. Contato

Dúvidas sobre esta política: abra uma solicitação em github.com/MiguelDalpim/MiguelDalpim.github.io/issues.
